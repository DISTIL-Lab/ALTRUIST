# ALTRUIST

A multi-platform research tool for subjective Quality of Experience (QoE) experiments: coordinate external applications, automate test execution, and streamline data collection.

**[Read the ALTRUIST documentation](https://distil-lab.github.io/ALTRUIST/)**

The documentation link becomes available after the files are pushed and GitHub Pages is enabled.

## Website source

Open `docs/index.html` in a browser for a local preview. Edit that file to change content and `docs/style.css` to change appearance. No build dependencies are required.

## Publishing

1. Commit and push these files to `main`.
2. Open the repository's **Settings → Pages** on GitHub.
3. Select **Deploy from a branch**, then **main** and **/docs**, and save.
4. Once published, add `https://distil-lab.github.io/ALTRUIST/` to the repository's About website field.

A GitHub link opens this repository README; the documentation link above opens the webpage.

[GitHub Pages publishing instructions](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
