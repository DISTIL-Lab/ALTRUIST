# ALTRUIST

A multi-platform research tool for subjective Quality of Experience (QoE) experiments: coordinate external applications, automate test execution, and streamline data collection.

**[Read the ALTRUIST documentation](https://distil-lab.github.io/ALTRUIST/)**

Developed by [DISTIL Lab](https://github.com/DISTIL-Lab) at Luleå University of Technology, Campus Skellefteå, Sweden.
