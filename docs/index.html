RESEARCH TOOLS / QUALITY OF EXPERIENCE

THE ALTRUIST GUIDE

Subjective experiments.
One coordinated workflow.

Control external applications, automate test execution, and streamline data collection for Quality of Experience (QoE) research.

Subjective experiments often require several applications and services to work together. ALTRUIST is a multi-platform tool designed to simplify this coordination and support consistent, repeatable test sessions.

About this guide

This initial guide describes the project’s core purpose, based on the Godot implementation README. Detailed interface instructions and examples will be added as the documentation develops.

01 / CAPABILITIES

What ALTRUIST helps you do

01

Control applications

Coordinate external applications used during subjective experiments.

02

Automate test execution

Support repeatable test procedures and reduce manual work between sessions.

03

Collect experiment data

Streamline data collection as part of the experiment workflow.

04

Coordinate distributed setups

Bring multiple components into a coordinated QoE testing environment.

02 / WORKFLOW

From setup to collected data

A high-level planning guide for an experiment:

  1. Define the experiment

    Identify the experience to evaluate, the test conditions, and the data you need.

  2. Prepare the environment

    Prepare the applications and devices involved in the test.

  3. Run a pilot session

    Verify application coordination and data collection before inviting participants.

  4. Conduct the sessions

    Follow a consistent procedure across participants, then review the collected data for analysis.

03 / SETUP

Getting started with the Godot implementation

The implementation README lists Godot 4.3 (exact version to be confirmed) and .NET SDK 8 for C# scripting. Confirm requirements in the implementation repository before installing.

  1. Obtain the Godot implementation source.
  2. Install a compatible Godot editor with C# support and the required .NET SDK.
  3. Import project.godot into the editor.
  4. Prepare your experiment environment and validate a pilot session.

For desktop builds, use Project → Export in Godot and install the appropriate export templates.
